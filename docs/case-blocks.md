# Case blocks

Блоки подключаются в тексте кейса через fenced-синтаксис:

```md
:::callout label="Гипотеза"
Текст блока.
:::
```

Всё вне `:::` продолжает обрабатываться прежним `formatCaseContent` без изменений. Незакрытый блок остаётся обычным текстом.

## Компоненты

Все компоненты лежат в `src/components/case-blocks/`. Стили используют токены проекта.

| Блок | Назначение |
| --- | --- |
| `CaseCallout` | Крупный вывод с моно-меткой и акцентной полосой. |
| `CaseCards` | Сетка карточек, опционально с номерами. |
| `CaseTriad` | Три колонки со стрелками между ними. |
| `CaseStats` | Плитки цифр в стиле hero. |
| `CaseQuad` | Матрица 2×2 с подписями осей. |
| `CaseSteps` | Горизонтальная/вертикальная цепочка шагов и вкладки сценариев. |
| `CaseChain` | Причинно-следственная цепочка. |
| `CaseChips` | Ряд моно-чипов. |
| `CaseRows` | Строки-карточки с ромбом. Используются в «Что я понял». |
| `CaseFindings` | Карточки «Хорошо / Ошибка» с картинкой. |
| `CaseGallery` | Сетка картинок с подписями и кликом по изображению. |
| `CaseStage` | Сцена для одной, двух или трёх картинок. |
| `CaseSlider` | Слайдер картинок на вкладках-метках или шагах. |
| `CaseFlow` | Схема из узлов и петель. |
| `CaseEmbed` | iframe с белым списком хостов, соотношением сторон и `maxwidth`. |

## Синтаксис

### Callout

```md
:::callout label="Гипотеза"
Если сократить путь до первой записи, пользователь вернётся завтра.
:::
```

Параметры: `label` — моно-метка.

### Cards

```md
:::cards cols=3 numbered
**Заголовок** | текст
**Заголовок** | текст
:::
```

Параметры: `cols=2|3|4`, `numbered`. Без `numbered` номера не показываются.

### Triad

```md
:::triad labels="Когда|Хочу|Чтобы"
Вечером | быстро записать трату | не забыть детали
Утром | увидеть остаток | принять решение
:::
```

Параметры: `labels` — три подписи через `|`. Каждая строка тела — один ряд из трёх значений.

### Stats

```md
:::stats
15+ | экранов
4 | сценария
40 сек | до первой записи
:::
```

Каждая строка: `значение | подпись`.

### Quad

```md
:::quad axes="INTERNAL|EXTERNAL|TECHNICAL|PRODUCT"
Верх-лево | текст
Верх-право | текст
Низ-лево | текст
Низ-право | текст
:::
```

Порядок `axes`: вертикаль сверху/снизу, затем горизонталь слева/справа. Все четыре значения можно переопределить.

### Steps

```md
:::steps
Определить задачу
Собрать гипотезы
Проверить прототип
:::
```

Строка `Заголовок | текст` также поддерживается.

### Steps with scenarios

```md
:::steps-tabs
# Сценарий 1
Первый шаг
Второй шаг
# Сценарий 2
Первый шаг
Второй шаг
:::
```

Вкладки работают по ARIA tabs: `←`, `→`, `Home`, `End`.

### Chain

```md
:::chain
Нет контекста
Сложно выбрать
Нет действия
:::
```

Рекомендуется 3–5 узлов.

### Chips

```md
:::chips
исследование, прототип, интервью, метрики
:::
```

### Rows

```md
:::rows
**Сначала контекст.** Без контекста решение выглядит убедительно.
**Потом проверка.** Гипотеза проверяется на реальном сценарии.
:::
```

Без `**...**` первая фраза до точки используется как заголовок.

### Findings

```md
:::findings
good | Заголовок | текст | /assets/example.webp
mistake | Заголовок | текст | /assets/example.webp
:::
```

Первое поле: `good` или `mistake`. Картинка необязательна.

### Gallery

```md
:::gallery cols=3
/assets/example-1.webp | Подпись
/assets/example-2.webp | Подпись
:::
```

Параметры: `cols=2|3`. Клик по картинке вызывает `openImageModal`.

### Stage

```md
:::stage layout=pair
/assets/desktop.webp | Десктоп
/assets/mobile.webp | Мобильный
:::
```

Параметры: `layout=single|pair|trio`. Внутри — сетка, grid-mask и мягкая подсветка цвета кейса.

### Slider

```md
:::slider
/assets/desktop.webp | Десктоп
/assets/mobile.webp | Мобильная версия
:::
```

Каждая строка: `путь | метка`. Метка одновременно служит подписью слайда, поэтому её стоит держать короткой («Десктоп», «Мобильная версия»). Пути с пробелами допустимы: разделитель — только первый `|` в строке. Любые лишние атрибуты (например, `mode=steps`) парсер принимает и игнорирует — вид у слайдера один.

Вид: сцена с картинкой и под ней одна строка по центру — круглая стрелка «назад», метка и счётчик `1/N`, круглая стрелка «вперёд». Стрелки циклические и всегда активны. Переключение: клик по стрелкам, `←`/`→` с клавиатуры при фокусе внутри слайдера, свайп на тач-экранах.

Все слайды лежат в одной ячейке grid (неактивные — `visibility: hidden`), поэтому высота блока равна самому высокому слайду и при переключении ничего не прыгает. Смена слайда — только `opacity` (≤180ms), при `prefers-reduced-motion` анимация отключается. Картинка ограничена `max-height: 640px` на десктопе и `520px` на мобильном, `object-fit: contain`.

Клик по картинке вызывает `openImageModal` с текущим слайдом. Если в блоке одна картинка, выводится просто картинка и подпись, без стрелок.

### Flow

```md
:::flow
circle | Старт | Пользователь открывает продукт
square | Первый шаг | Выбирает сценарий
diamond | Проверка | Понимает следующий шаг
loop 3>2 | нет
:::
```

Узлы: `circle`, `square`, `diamond`. Петли: `loop <откуда>><куда> | подпись`.

### Embed

```md
:::embed url="https://embed.figma.com/proto/…&embed-host=share" ratio=16:9 mobileratio=4:5 maxwidth=800 title="Кликабельный Figma-прототип Hired"
:::
```

Встраиваемый контент (iframe). Без строк внутри. Параметры:

- `url` — обязательный, всегда приводится к `https://`.
- `ratio` — соотношение сторон контейнера по умолчанию (`16:9`).
- `mobileratio` — соотношение на ширине ≤640px, если задано.
- `maxwidth` — максимальная ширина контейнера в пикселях.
- `title` — обязательный текст для доступности (`title` у iframe).
- `sandbox` — по умолчанию атрибут не ставится. `sandbox=wide` применяет набор `allow-same-origin allow-scripts allow-pointer-lock allow-forms allow-popups allow-popups-to-escape-sandbox`. Для Figma sandbox не ставится, а iframe получает `allowfullscreen`.

Белый список хостов: `embed.figma.com`, `www.figma.com` (только путь `/embed`), `cdn.knightlab.com`. Если `url` не с этих хостов, блок ничего не выводит и пишет предупреждение в консоль. Парсер разбирает значения в кавычках как строки, поэтому `=`, `&` и `%` внутри длинного URL не ломают параметры.

## Акцентные слова

В заголовках глав и `lead` текст внутри `*звёздочек*` выводится цветом `var(--accent)` без курсива:

```md
*Быстрый* вход в продукт
```

В остальных местах этот синтаксис не применяется.

## Dev-страница

В dev-режиме доступна страница `/dev/blocks` с примерами всех блоков. В production-сборку страница не включается.
