## How I work

A loop of seven steps: problem → hypotheses → scenarios → logic (checked in a prototype) → design → implementation → validation. If a step doesn't hold, I go back to an earlier one.

## Skills

Product logic, MVP design, UX research, information architecture, design systems, prototyping, responsive design, vibe coding, product metrics and validation planning.
