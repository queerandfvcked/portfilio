## Summary

Product designer focused on B2C web and mobile interfaces. I take a product from problem and research through user flows and UI to a working React prototype built with AI coding agents: I own the design, product logic and prompts, the agent writes the code.

## Scope of this portfolio

The portfolio consists mainly of self-initiated case studies. No metrics from commercial work are claimed. Where a case describes an expected effect, it is a hypothesis, not a measured result.

## Projects

### Zhabka — personal AI vacancy assistant
Status: working; I use it myself.
- Collects vacancies from Telegram and keeps the relevant ones: about 170 posts a day down to 5–10.
- Six product decisions are described in the case, for example explaining why a vacancy matches instead of showing a match percentage.
- Stack: React + Vite, JavaScript, CSS, PWA; Python + FastAPI (REST); Telethon (MTProto); Gemini API (gemini-3.1-flash-lite) and OpenRouter; local JSON files.
- Case: https://andrianshtark.vercel.app/en/zhabka

### Keepl App — web app for reaching goals without guilt
Status: MVP, pre-launch. No usage data yet.
- Flexible, partial progress instead of binary "done / not done"; a lighter alternative of a step; mood and photo context.
- 15+ screens, 50+ components. Team of two: I did research, UX/UI and the React front end (with AI tools); a teammate built the back end.
- Validation plan only (30-day retention, stickiness, feature adoption, completion rate). Expected effects are hypotheses.
- Case: https://andrianshtark.vercel.app/en/keepl-app

### Keepl Landing — landing page for Keepl
Status: published (https://keepl.vercel.app/). Its effect on conversion and activation has not been measured.
- Case: https://andrianshtark.vercel.app/en/keepl-landing

## How I work

A loop of seven steps: problem → hypotheses → scenarios → logic (checked in a prototype) → design → implementation → validation. If a step doesn't hold, I go back to an earlier one.

## Skills

Product logic, MVP design, UX research, information architecture, design systems, prototyping, responsive design, vibe coding, product metrics (validation plans).
